# Florida plan review

Review the current project's permit packet before submittal or resubmittal. Find specific issues a jurisdiction may comment on. Use the [shared review method](REVIEW_METHOD.md) and the discipline files below. Historical comments may suggest a check, but only this project's documents and governing sources establish a finding.

## Start here

1. Read the cover, permit application, index, general notes, available agency letters, and previous comments. Record the jurisdiction and agencies, address/parcel, scope, occupancy/use, construction type, permit stage, submittal date, units, code path, and each governing code edition. Cite the project document or official adoption source for each value. Mark unknowns `Needs input`.
2. Inventory every sheet, calculation, report, form, and revision. Assign each scope below to its reviewer. Give all reviewers the same project configuration and only the sheets and supporting documents they need. Split large sets into manageable sheet batches; do not skip sheets.
3. Have reviewers apply [REVIEW_METHOD.md](REVIEW_METHOD.md) and their discipline file. Merge findings and code-citation logs. Check cross-discipline values, open references, missing packages, and prior-comment closure. Independently recheck Critical findings and disputed code claims.
4. Deliver the report specified in the shared method. Keep unresolved source access and missing inputs visible.

| Occupant load, egress, rated construction | [Life safety](disciplines/life_safety.md) |

| HVAC, ventilation, exhaust, controls | [Mechanical](disciplines/mechanical.md) |
| Power, lighting, service, grounding | [Electrical](disciplines/electrical.md) |
| Water, sanitary, gas, roof drainage | [Plumbing](disciplines/plumbing.md) |
| Alarm and detection system | [Fire alarm](disciplines/fire_alarm.md) |
| Sprinkler and standpipe system | [Fire sprinkler](disciplines/fire_sprinkler.md) |
| Fire service, apparatus access, system interfaces and fire permits | [Fire protection](disciplines/fire_protection.md) |

Route the fire disciplines separately: Fire Alarm and Fire Sprinkler check system design; Life Safety checks code analysis and egress; Fire Protection checks their site, building, permit, and agency interfaces. General applies to the full packet. When a discipline has no work, record `Not applicable` with the reason. When referenced sheets or deferred packages are absent, identify the review boundary and check the authority's permitted submission stage.
