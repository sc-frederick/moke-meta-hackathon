# General and permit-set review

Apply the master `AGENTS.md` and `REVIEW_METHOD.md`. Own the cover, application, sheet index, general notes, agency conditions, supporting-document inventory, and resubmittal response. Send trade-specific defects to that reviewer.

## Required inputs and sequence

Collect the full current permit packet and all prior comment/response cycles for this permit. Index every document and revision. Establish the project configuration and adopted source list, then compare the cover/application to each discipline's stated data. Track every comment to the actual changed deliverable.

## Permit identity and code basis

- Compare project name, address, parcel, owner, permit scope, existing/proposed work, use, occupancy, construction type, areas, building height, and flood information across the application, cover, site plan, and discipline sheets.
- List each adopted code, edition, amendment, and code path actually used. Check the permit's governing date and any existing-building or alteration path. Flag mixed residential/building paths, stale editions, and unexplained differences between sheets.
- Check drawing index against every submitted sheet and every "see sheet" reference. Confirm required seals, signatures, certifications, product approvals, reports, and separate permits against the authority's current submittal rules, not a past permit's checklist.
- Reconcile zoning approvals, development orders, variances, conditions, utility/service availability, and agency letters with the design. Record conditions that cannot yet be tested.

## Document quality and coordination

- Check title blocks, sheet numbers/titles, north arrows and scales where needed, issue dates, revision identifiers, legends, schedule completeness, detail references, and legibility.
- Search the entire set for blank fields, sample text, inconsistent building names, wrong addresses, conflicting areas or room names, and notes describing work absent from the plan. Reconcile shared design data across disciplines.
- Identify delegated or deferred work, its design criteria and interfaces, the responsible professional, and the submission stage approved by the authority. Record the exact review boundary.

## Revision closure

- Make one row per current and prior jurisdiction comment with agency, date, number, response, changed sheet/report/form, and status. Read the changed item; a response letter alone is not proof of correction.
- Recheck changed sheets for new conflicts and repeated comments. Mark superseded comments only when the scope or authority record supports it.

## Release check

Confirm that the sheet index matches the packet, each discipline has a review status, every required separate or deferred package has an approved path, source editions are consistent, and each prior comment has an evidence-based disposition.
