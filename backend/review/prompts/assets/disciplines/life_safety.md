# Life safety review

Apply the master `AGENTS.md` and `REVIEW_METHOD.md`. Own occupancy and egress analysis, rated construction, and life-safety plan coordination. Verify applicable Florida Building Code and Florida Fire Prevention Code provisions and local amendments before using a numeric threshold.

## Required inputs and sequence

Collect the code analysis, current life-safety and architectural plans, occupant-load calculations, rated assembly listings and relevant fire, electrical and mechanical sheets. Identify the actual use of every room. Recalculate loads and trace complete exit paths before evaluating the shown fire systems and ratings. Review each past life-safety/fire comment against the revised documents.

## Occupancy and egress basis

- Match actual room uses and existing/proposed scope to occupancy classifications, mixed-use approach, construction type, occupant-load factors, areas, and table totals. Recalculate occupant loads and egress capacities with the adopted method and its rounding rule.
- Mark the most remote occupied points on the plan. Trace egress through common paths, corridors, stairs, doors, exit passageways, discharge and public way. Check the number of exits, numeric travel/common-path/dead-end lengths shown on plans, exit separation, widths, capacity, and accessible egress where applicable.
- Check door swings, hardware, clear widths, stair/landing/guard/handrail dimensions, under-stair space, ramps, exterior landings and egress courts against the actual occupancy and route.
- Compare exit signs, emergency/standby lighting, power source, smoke or CO alarms, and fire extinguishers with electrical, alarm, and architectural plans. Check required class, placement, and location rather than inferring compliance from a legend.

## Fire and smoke protection

- Locate required fire barriers, partitions, horizontal assemblies, shafts, corridors, tenant/unit separations, and exterior-wall opening protection. Check ratings, continuity, doors, fire damper locations, joints, and penetrations against listed systems and actual construction. Recalculate or check the fire-separation-distance/openings table when applicable.
- Review fire separation distance, opening area, finishes, fireblocking/draftstopping, storage and special-use rooms where applicable. Check sprinkler/alarm assumptions used to obtain a code exception.
- For residential or altered sleeping rooms, coordinate emergency escape openings and smoke/CO alarm locations with the room layouts and fuel-burning/garage conditions.
- Record discrepancies with both affected sheets. If a system is referenced but separately permitted, identify which life-safety determination cannot yet be confirmed.

## Revision and release

Match each prior life-safety/fire comment to the revised analysis, plan or detail. Before release, compare the final occupant-load table, paths, signs, lighting, extinguisher classes, separation table, assembly references and system assumptions across disciplines.
