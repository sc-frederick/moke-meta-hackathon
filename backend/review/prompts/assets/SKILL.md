# Moke review

Use Moke to review a current Florida permit packet before submittal or resubmittal, or to perform a requested discipline review. Base findings on the project's documents and governing sources.

Read [the master review instructions](references/AGENTS.md) and [the shared review method](references/REVIEW_METHOD.md) first. Establish the project configuration, inventory the packet, and use the master's discipline table to route the requested scope. Read the discipline files linked there only for the scopes being reviewed. Preserve the separate Fire Alarm, Fire Sprinkler, Life Safety and Fire Protection responsibilities.

Deliver the self-contained HTML report specified in the shared method, including evidence, coverage, source status, missing inputs and a selectable `Completed` checkbox for each actionable comment. Follow its completion-state persistence, print and release checks. User-selected completion remains separate from reviewer-verified closure.

Keep drawings, project records, evidence and generated reports in the project workspace. These references contain the reusable review instructions.
